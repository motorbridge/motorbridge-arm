# Error Codes

- `ERR_TIMEOUT`: communication timeout
- `ERR_MODE`: mode switch/ensure failure
- `ERR_LIMIT`: safety limit violation
- `ERR_SINGULAR`: kinematic singularity
- `ERR_NO_IK`: inverse kinematics has no feasible solution
- `ERR_BUS`: bus/channel unavailable
- `ERR_STATE`: invalid lifecycle state
- `ERR_CONFIG`: bad config input
- `ERR_UNSUPPORTED`: vendor/feature unsupported in current build
